# Excel 格式测试用例输出规则

质量遵 `functional-testcase-design.md`。本文件只约束 **CSV 物理格式**（Excel / WPS 可打开；不生成 `.xlsx`）。

路径：`testcases/{需求名称}-测试用例.csv`。**同一需求只写一份文件**，不论条数；禁止拆成 `-01`/`-02`。用户指定了目录则写到该目录；仅当用户明确要求拆分时才分文件。

---

## 固定 11 列（顺序不可改）

编码 **UTF-8 with BOM**（文件头 `\uFEFF`），分隔符英文逗号。含逗号/引号/换行的字段用双引号包裹，内部 `"` 写成 `""`。
注意：多数编辑器 / Write 工具写出的文件**不带 BOM**，Excel 直接打开中文会乱码。写完后运行 `python scripts/validate_testcase.py --fix-bom <csv>` 补齐，再交付。

**范围声明的归属**：固定 11 列没有位置放范围声明，不要为它在 CSV 里加行或加列。缺口 / 待确认写进给用户的回复正文，并在相关用例的「预期结果」或「备注」列标【待确认】。

| 列序 | 列名 | 约束 |
|------|------|------|
| 1 | 用例编号 | `TC001` 或 `TC1-001`，连续不跳号 |
| 2 | 功能模块 | 同类行取值一致，便于筛选 |
| 3 | 功能测试点 | 对应 XMind 的功能点或场景分组（字段 / 规则分支），不要填「功能测试」 |
| 4 | 验证维度 | 只能填 3.2 的 11 个标准名之一（仅作列值，不是脑图节点） |
| 5 | 用例标题 | 条件 + 操作，与 XMind 标题同一写法；≤25 个汉字（计数见 functional 第四章），不要把 TC/P0 写进标题 |
| 6 | 优先级 | 只允许 `高` / `中` / `低`（高=P0，中=P1，低=P2） |
| 7 | 前置条件 | 执行前状态与数据；无则 `无` |
| 8 | 测试步骤 | 带序号，多步换行（字段整体加引号） |
| 9 | 预期结果 | 可判定；多条换行 |
| 10 | 实际结果 | 生成时填 `—` |
| 11 | 备注 | 无则留空（仍要保留列） |

排列：模块 → 功能点 → 维度（顺序见 3.2）→ 同维度高优先级在前。字段值不要以 `=` `+` `-` `@` 开头（Excel 当公式）。

下面样例只演示列结构与转义。需求未给提示原文或表结构时，预期只写可见层或【待确认】，**禁止把样例里的句子抄成已确认事实**。

```csv
用例编号,功能模块,功能测试点,验证维度,用例标题,优先级,前置条件,测试步骤,预期结果,实际结果,备注
TC001,注册页-提交区,手机号,功能测试,仅填未注册的11位手机号和正确验证码，点击注册,高,用户未注册,"1. 打开注册页面
2. 输入手机号 13800001111
3. 获取并输入正确验证码
4. 点击注册","1. 注册成功，跳转至首页",—,
TC002,注册页-提交区,手机号,功能测试,输入已注册手机号和正确验证码后点击注册,高,该手机号已注册,"1. 打开注册页面
2. 输入已注册的手机号
3. 获取验证码并输入
4. 点击注册","1. 拦截且不创建新账号
2. 提示文案【待确认】",—,
TC003,注册页-提交区,手机号,边界测试,输入10位数字手机号后点击注册,中,用户未注册,"1. 打开注册页面
2. 输入 10 位数字 1380000111

TC004,注册页-提交区,验证码,异常测试,验证码过期后点击注册,中,验证码已超过有效期,"1. 打开注册页面
2. 输入手机号并获取验证码
3. 等待过期后点击注册","1. 提交被拒，须重新获取验证码",—,
```

自检：11 列表头；每行 11 字段；BOM；优先级只有高/中/低；标题非空、≤25 汉字且不含 TC/（P0）。
